🛡️ AI Vendor Risk Assessment Automator

Turn vendor security docs into a preliminary third-party risk assessment. Every extracted claim is cited to its source page — anything the documentation doesn't support is marked "Not verified" rather than guessed.

How It Works

📄

Upload Vendor Docs

Privacy policies, security whitepapers, SOC 2 reports, DPAs

🔍

Screen for Injection

Vendor PDFs are untrusted input — we detect and redact prompt-injection attempts

🎯

Extract Evidence

Answer 21 risk questions. Unverifiable claims marked "Not verified"

📊

Score & Map

Deterministic rule-based scoring (no model decides risk). Map to NIST AI RMF
